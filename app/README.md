# Mission Replay — демо-застосунок

Вебзастосунок для живої демонстрації: дрон «летить» по мапі кадр за кадром. Ліворуч — кадр камери, праворуч —
мапа з маршрутом, що наростає, контуром поточного кадру й курсом. Унизу — статистика, графік inliers і таймлайн
для повторного перегляду.

## Запуск

```powershell
pip install -r requirements.txt -r requirements-app.txt   # + requirements-learned.txt для навчених методів
python -m app                    # http://127.0.0.1:8080
python -m app --host 0.0.0.0     # доступ з інших пристроїв у локальній мережі
```

Готові набори з'являються автоматично, якщо дані є локально:
- 50 кадрів завдання — `python scripts/download_data.py`;
- синтетика з GT — `scripts/make_synthetic.py --out data/synthetic_map --world data/train/global_map.png --frame-scale 0.25 --frame-size 640x640`;
- власні відео й райони — за `configs/datasets.yaml`.

## Можливості

- **Джерело:** готовий набір із `configs/datasets.yaml` або свої дані — мапа (за замовчуванням мапа завдання)
  і фото кадрів або одне відео. З відео береться кожен N-й кадр; якщо OpenCV не читає HEVC `.MOV`, відео
  перекодовується через `ffmpeg`, якщо той є в PATH.
- **Метод:** бейзлайн, фінальний SIFT + LightGlue, класичний трекінг (SIFT / AKAZE / ORB) і навчені методи.
  Методи без потрібних пакетів (torch, lightglue, kornia) показані неактивними.
- **Мапа:** колір маршруту — час, контури кадрів, поточний кадр (жовтий край — верх кадру, стрілка — курс),
  справжній маршрут для наборів із GT, позначки START / FINISH. Режими «Слідкувати» і «Уся мапа», масштаб
  коліщатком, перетягування мишею.
- **Після завершення:** таймлайн і відтворення з вибором швидкості, клік по графіку inliers переходить до кадру,
  завантаження `route.png`, `trajectory.csv`, `metrics.json`.
- **Посилання на момент:** `http://127.0.0.1:8080/#job=<id>&k=<кадр>&view=fit`.

## Як влаштовано

- `app/server.py` — FastAPI: створення задачі (multipart), потік подій через Server-Sent Events, прев'ю мапи
  й кадрів, файли результатів.
- `app/jobs.py` — черга з одним виконавцем (одна GPU), витягування кадрів із відео, журнал подій задачі.
  Журнал можна читати з будь-якого місця, тому завершену місію можна відкрити й відтворити знову.
- `app/catalog.py` — список методів (YAML-конфіги з `configs/map/`) і наборів.
- `app/static/` — фронтенд без збірки (HTML + CSS + JS, мапа на `<canvas>`).
- Сам конвеєр не змінено: `vo.localize.run_localization` отримав необов'язковий колбек `progress`, через який
  застосунок отримує кожен кадр.

Результати пишуться в `experiments/results/app/<job_id>/`, завантажені файли — у `data/app_uploads/<job_id>/`.
Обидві папки не версіонуються. Задачі зберігаються лише в пам'яті сервера: після перезапуску список місій
порожній, хоча файли результатів лишаються на диску.
